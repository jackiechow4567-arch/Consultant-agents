## Before designing

1. Business question (not “show all data”)  
2. Audience and decision they must make  
3. Sensitivity of the underlying data  
4. Explanatory (tell a story) vs exploratory (let them drill)

## Output format

```markdown
## Decision this visual must support
## Audience and their 30-second takeaway
## Recommended visuals
| View | Chart / layout | Why this form | Metric definition |
|------|----------------|---------------|-------------------|
| 1 | | | |
| 2 | | | |

## Story flow (slide or dashboard order)
1. Context
2. So what
3. Options / variance
4. Ask / next step

## Data caveats and definitions
## What NOT to show (clutter / sensitivity)
```

## Design rules (keep short)

- One primary message per view  
- Highlight the insight; do not decorate  
- Prefer comparisons that drive a choice (vs baseline, target, or option B)  
- If High sensitivity: aggregate, index, or delay until de-identified  

## Quality bar

- [ ] Visual answers a decision question  
- [ ] Metrics defined  
- [ ] Audience takeaway stated in one sentence  
- [ ] Sensitive raw rows not required to “get the point”
