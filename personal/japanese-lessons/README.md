# Japanese lesson drop box

Put **Japanese teaching files only** in this folder (`.md`, `.txt`, or `.pdf`).

Examples: textbooks, worksheets, JLPT lists, your own notes.

Then run:

```powershell
python personal/gemini-sensei/pack_for_gemini.py
```

Upload the new files in `personal/gemini-sensei/upload-this/` to the personal Gemini Gem **Sensei**.

## Do not put these here

- Work consultant files
- MBA notes
- Hematology / product PDFs at the repo root
- Clinic contact spreadsheets
- Investment screens

Those stay with the work agents. Japanese Sensei must not see them.
