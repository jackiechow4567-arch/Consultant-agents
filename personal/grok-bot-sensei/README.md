# Grok Bot Sensei (Japanese only)

This Bot is a Japanese teacher. Do not attach work files or other agents to it.

1. Grok Bot app → **New** → **Create new agent**.
2. **Edit Profile** — paste [bot-profile.md](bot-profile.md).
3. Send [first-message.md](first-message.md).
4. If the lesson is good, paste [skill-daily-lesson.md](skill-daily-lesson.md), then [routine.md](routine.md).
