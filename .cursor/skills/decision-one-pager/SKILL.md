# Decision One-Pager

## When to use

User needs an executive-ready decision memo (do X / don't Y) for Product Manager or General Manager context.

## Instructions

1. Read and follow:
   - `consultant-agents/playbooks/decision-one-pager.md`
   - `consultant-agents/agents/04-product-gm.md`
2. Confirm sensitivity tier and audience. If high, write two versions: full local memo + de-identified shareable memo.
3. If options are missing, propose 2–3 plausible options, then recommend one.
4. Output must start with an explicit recommendation: **做 X；不做 Y。**
5. Include: scoring table, explicit non-goals, 對上 5 句, 對下 5 句, next actions with roles, assumptions/gaps.
6. Do not end with only "gather more information" unless the gap is fatal; if so, list the minimum info checklist.
7. Do not invent financial or clinical metrics; mark unknowns as TBD.

## Optional save path

`consultant-agents/work-briefs/YYYY-MM-DD-<topic>-decision.md` (local) or a de-identified copy for sharing.
