# BESREMi PM competency training

> Role lens: **Product Manager** (PharmaEssentia HK).  
> Sensitivity: **Mid** — uses distilled PI, published evidence, HKAPI/UMAO, and role-memory access facts already in this vault. Do not paste into Perplexity.  
> Not a medical textbook. Goal: you can run on-label commercial decisions without inventing claims.

## How to use

1. Read [`besremi-pm-training.md`](besremi-pm-training.md) (eight modules + pocket card). Or open the interactive pack: [`besremi-pm-training.html`](besremi-pm-training.html).
2. Close the notes. Sit the closed-book test: [`besremi-pm-self-test.md`](besremi-pm-self-test.md) (or the quiz in the HTML).
3. Score against [`besremi-pm-answer-key.md`](besremi-pm-answer-key.md).

## Pass bar

| Score | Meaning |
|-------|---------|
| 18–20 | Field-ready |
| 16–17 | Competent — restudy missed modules |
| ≤15 | Repeat the pack before HCP-facing work |

**Hard-constraint override:** miss any of Q5, Q9, Q10, Q15, or Q18 (IFN-to-IFN superiority, ET/MF proactive use, branded POM items, off-label promo) and you restudy Module 1 + Module 6 even if the total score is high.
