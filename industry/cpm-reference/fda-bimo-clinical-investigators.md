# FDA BIMO CP 7348.811 — Clinical Investigators (distilled)

> Source: `CP7348-1.pdf` (FDA CP **7348.811**, Clinical Investigators and Sponsor-Investigators; implementation **22 Jul 2020**)

## Purpose

Same BIMO goals at the **clinical investigator / site** level: subject protection, data reliability, regulatory compliance.

## How Senior CPM uses this

- Prep sites and Associate CPM for **site inspections** (not only sponsor/CRO audits)  
- Align site readiness checklist themes with what FDA looks for at CI level  
- Coach: answers must match source documents; no speculation to inspectors  

## Typical CI inspection themes (align with site readiness checklist)

- Delegation of authority / retained CI control and knowledge  
- IRB: initial, continuing, amendments, ICF versions, communications, SAE/death reporting  
- Form FDA **1572** versions  
- Protocol adherence: eligibility, randomization, blind, procedures, deviations (report to IRB + sponsor)  
- Informed consent process (**21 CFR 50**) — correct version, signed before procedures, LAR rules  
- IP storage, accountability, dosing per protocol  
- Source records completeness/accuracy; primary endpoint data  
- Lab/diagnostic facilities and CLIA where applicable  
- Subject recruitment / IRB-approved ads  

## Classification

Same NAI / VAI / OAI framework as other BIMO programs.

## Link to role memory

- Site staffing and CRO–site communication failures → CI inspection risk  
- Block site activation / monitoring visit if open TMF “Requires Action” on safety, consent, or IP accountability
