# Site inspection readiness (de-identified themes)

> Distilled from Space readiness agenda/checklist templates (Feb 2026). **No site names, investigators, or visit findings** in this file.  
> Site-specific decks/reports/trackers → `work-briefs/cpm/` index only.

## Purpose

Pre-inspection / mock readiness for investigational sites supporting FDA-usable OUS data (SURPASS ET / HOPE PMF context).

## Checklist domains (Present / Requirement / Comment pattern)

1. **Study inventory** — studies by CI (protocol, sponsor, status, dates, subject counts) — use counts only when de-identified  
2. **CI changes** — documentation, sponsor + IRB approval  
3. **Locations** — where visits conducted  
4. **Training** — IP, protocol, e-systems, CI obligations from sponsor  
5. **Delegation of Authority** — qualifications; CI retained control/knowledge  
6. **IRB/IEC** — chair, initial/continuing approval, protocol/ICF changes, communications, prompt reporting (deaths, SAEs, risks)  
7. **1572** — all versions  
8. **Milestone dates** — first consent, screen, randomize, first/last IP, last visit, close; CI discontinuation + IRB notify  
9. **Labs** — facilities, CLIA  
10. **Recruitment** — process; IRB-approved ads  
11. **Screening/enrollment logs** — reconcile counts by arm (no subject IDs in agent outputs)  
12. **Protocol & amendments** — IRB approvals; planned exceptions; immediate hazard changes  
13. **Protocol adherence** — eligibility, n enrolled, randomization, blind/unblind, procedures  
14. **Deviations** — reported to IRB + sponsor; dates/reasons; prevention actions  
15. **IP** — storage, accountability, dosing/route/frequency, escalation/stopping rules, communication of serious findings  
16. **Data** — primary endpoint collection; line-listing accuracy  
17. **Informed consent** — versions, 21 CFR 50, signed before procedures, copy to subject/LAR  

## Agenda / visit report pattern (process only)

| Step | Owner (typical) |
|------|-----------------|
| Pre-brief site on interview discipline | Associate CPM drafts; Senior CPM reviews materials |
| Walk checklist domains | Site + CRO; sponsor oversight samples |
| Document gaps → CAPA with root cause + effectiveness date | CRO/site; Senior CPM approves closure |
| Update inspection-readiness tracker | Associate CPM; Senior CPM samples |

## Agent rules

- Output **domain-level** gaps and next actions — never subject IDs or named investigators  
- Sensitivity: Mid for generic checklist coaching; **High** if discussing a named site’s visit report
