# Employee handbook — HK subsidiary patterns (generic)

> Source: `Handbook-text.docx` template on user Desktop — **de-identified generic patterns only.**  
> **Not** PharmaEssentia live policy. Confirm all terms with HR/Legal before applying.

## Hierarchy of documents

1. **Employment Ordinance + HK law** (prevail)
2. **Individual employment contract** + confidentiality/IP/training agreements
3. **Employee handbook** (cannot override contract or law)

Handbook may be updated by company; latest published version prevails.

## Employee categories (typical MNC HK template)

| Category | Handbook coverage |
|----------|-------------------|
| Full-time local | Full handbook |
| Part-time (≤4h/day, ≤24h/week avg) | Often disciplinary + business conduct only |
| Seconded expatriates | Often disciplinary + conduct; home entity employment |
| Agency/temp staff | Service relationship with agency; company supervision rules still apply |

## Section map (GM-relevant)

### Employment management (hire → exit)

| Topic | Pattern |
|-------|---------|
| Recruitment | Approved requisition; background checks; EO-compliant offers |
| Onboarding | Orientation, IT access, compliance training |
| Probation | **3–6 months** typical; manager evaluation **≥2 weeks** before end; written confirmation on pass |
| Failed probation | Immediate termination if not meeting requirements (per handbook + EO) |
| Renewal | Mutual agreement; EO-compliant renewal |
| Resignation | Written notice per contract; exit checklist (ID, laptop, keys, IP return) |
| Summary dismissal | Willful disobedience, misconduct, fraud, habitual neglect (EO grounds) |
| Termination with notice | Underperformance post-PIP, restructure, medical incapacity, material change in circumstances |
| Exit interview | HR/manager capture reasons for leave |

### Compensation (patterns only)

- **Pay for performance** philosophy
- **Job grades** (e.g. level 100–210); People Manager vs Individual Contributor streams
- Merit review cycle (template: July effective; eligibility if joined before March 31)
- Market surveys for external competitiveness

### Performance

- Key competency model + annual performance process
- **Performance Improvement Plan (PIP)** before some terminations

### Policies GM should know exist

- Working time / leave management
- Disciplinary policy
- Business conduct / integrity
- IT assets, travel, mobile phone
- Recognition programs
