# 審閱清單

內文只改香港中文寫法。病名已改成香港用法，意思不變。數字、藥名、基因名和參考文獻照原文。

病名對照：

- 真性紅血球增生症、多血症 → 真性紅血球增多症（polycythaemia vera, PV）
- 原發性血小板增生症、原發性血小板過多症、血小板增生症、真性血小板增多症 → 原發性血小板增多症（essential thrombocythaemia, ET）
- 原發性骨髓纖維化症 → 原發性骨髓纖維化（primary myelofibrosis, PMF）
- 骨髓纖維化早前期 → 纖維化前期（pre-PMF）
- 骨髓纖維化明顯期 → 明顯纖維化期（overt PMF）
- 續發性骨髓纖維化 → 繼發性骨髓纖維化
- 後天性類血友病 → 後天性血管性血友病
- 鐮刀型貧血症 → 鐮刀細胞貧血
- 地中海貧血症 → 地中海貧血

骨髓增生性腫瘤香港與台灣相同，所以保留。「紅血球增生」「血小板增生」是指細胞增生，不是病名，所以保留。

沒有改成另一個醫學概念的用詞：血紅素、血比容、造血素、尺骨中靜脈、臨床檢驗科、骨髓切片、生長激素、骨髓幹細胞移植。文獻題目裡的 Polycythemia Vera、essential thrombocythemia 照原文。
