# Investment tools

Open the **repo root** in Cursor, not this folder:

- **File → Open Folder** → `Consultant-agents/`
- or open `Consultant-agents.code-workspace`

Consultant skills, agents, and MCP config load from `.cursor/` at the repo root. Opening only `investment/` hides the rest of the vault.

TradingView one-click setup: run `SETUP-TRADINGVIEW.bat` here or at the repo root. Both configure the **parent** `Consultant-agents` workspace.
