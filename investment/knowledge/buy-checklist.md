# Buy checklist (pre-order)

Ask every item. A single hard fail = **no buy today**. Soft fails go in the brief as defects — JLaw doctrine is not to accept a broken buy point.

Inspired by the user's Train-the-Trader buy guideline. Research support only.

## Setup quality

- [ ] Pivot / consolidation has run **≥3 days**
- [ ] Pocket pivot (if used) has run **≥3 days**
- [ ] Volume **dried up** while the base formed
- [ ] Base range **<10%** (tight, not loose)
- [ ] Pattern is constructive (not a wide, sloppy range)
- [ ] Base has had enough time to form (weeks, not one noisy day)

## Trend and RS

- [ ] RS meets buy standard; RS line is at/near a **new high**
- [ ] 50-day and 200-day both sloping **up**
- [ ] Price **above** the 50-day
- [ ] If under the 50-day, distance is **≤8%** (otherwise wait)
- [ ] Price **above** the 200-day
- [ ] Not a cheap stock (reject low-price / crowded retail names)

## Entry location

- [ ] Within **5%** of the breakout (prefer **3%**, best **2%**)
- [ ] Not chasing an already-extended move
- [ ] Next follow-on add is identified **before** the first buy (do not add randomly)

## Risk

- [ ] Technical stop exists
- [ ] Stop distance **≤8%**
- [ ] Reward:risk **≥2:1**
- [ ] Position-size plan is written (sleep-well size; no giant size into earnings)
- [ ] Stop order will be placed at send **or immediately after fill**

## Context

- [ ] Sector is strong
- [ ] Name is among the **leaders** of that sector (not the laggard)
- [ ] Liquidity is real (not a thin name)
- [ ] Fundamentals **support** the move (they do not replace the chart)
- [ ] Tape regime is known: easy vs grind; if grind, user is explicit
- [ ] If the tape has already run a long way, this name still deserves one of **10 slots this year**

If you would not put this name in a 10-stock annual budget, it does not go on today’s buy list.
