# Skill — Position / watchlist review

Save in Grok Bot as **Position / watchlist review**.

```text
When to use: after the screen + catalyst pass, or when the user pastes holdings.

Required inputs:
- investment/playbooks/position-review.md
- investment/knowledge/sell-checklist.md
- Watchlist or holdings the user provided (rounded weights OK)

Sequence:
1. For each name: thesis still valid? stop still valid? within 8% risk line?
2. Lock-profit: discuss trims at 1× stop, at +15–20%, and on climax/exhaustion — do not hunt the exact top.
3. Risk-control: stop hit, >8% down, heavy-volume break of 20/50-day, hostile tape + margin → sell language, no debate.
4. Kill any average-down suggestion.
5. Keep the working list short. Names that no longer earn a slot go to “drop from watchlist.”

Validate:
- No new method of the week.
- High-sensitivity account dumps are refused; ask for tickers + rounded weights only.

Return: the position-review playbook template.

Approval: user executes. Bot does not touch the broker.
```
