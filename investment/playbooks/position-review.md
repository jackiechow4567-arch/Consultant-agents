# Playbook — Position / watchlist review

Daily or after the morning screen. Combine with `knowledge/sell-checklist.md`.

---

## Input

Prefer `investment/watchlist.md` (local, gitignored). Until that exists, use tickers the user pastes or `templates/watchlist.example.md`.

Ask for **rounded weights** only. Refuse broker CSV / tax lots in this thread.

```markdown
| Ticker | Sleeve | Weight % (rounded) | Entry thesis | Stop | Still valid? |
|--------|--------|--------------------|--------------|------|--------------|
```

## Steps

1. Re-read regime. In grind / 血汗錢, new risk is off unless the user overrides.
2. Thesis audit: Valid / Weakened / Invalid.
3. Risk: stop, 8% line, 20/50-day break on heavy volume.
4. Lock-profit: 1× stop, +15–20% trims, climax at highs; keep a runner on the strongest name.
5. Drop names that no longer earn a scarce slot.
6. No averaging down. Adds only at the **next valid buy** on a working name.
