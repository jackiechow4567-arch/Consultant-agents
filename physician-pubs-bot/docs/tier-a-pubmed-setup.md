# Tier A — PubMed alerts (optional; skip if you research manually)

> **Not required.** This path needs a free **My NCBI** login and email/RSS alerts.  
> If you only run occasional searches yourself, use [`self-service-research.md`](self-service-research.md) instead.

## Spreadsheet

Maintain [`tier-a-pubmed-roster.csv`](tier-a-pubmed-roster.csv) with one row per target physician.

## Per-physician setup (only if you want alerts)

1. Open [PubMed Advanced Search](https://pubmed.ncbi.nlm.nih.gov/advanced/).
2. Author: `LastInitial[Author]` e.g. `Gisslinger H[Author]`.
3. Optional **Affiliation** or **Title/Abstract** filters.
4. **Search** → **Create RSS** or save search → **Email alerts** (requires My NCBI account).

## Tips

- Add ORCID when known.
- For common surnames, combine author + affiliation + one TA keyword.
