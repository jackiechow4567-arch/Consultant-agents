## 2. Strategy Triangle (detailed)

```
                    PURPOSE / DRIVING FORCE
                              │
    CUSTOMERS ──── VALUE PROPOSITION ──── PRODUCTS
         │                                    │
    MARKETS ────────── CHANNELS ───────── ACTIVITY MAP
                              │
              RESOURCES · CORE COMPETENCES · VALUES · PROCESSES
```

**Alignment test:** Every major initiative should trace to a product/market choice AND leverage internal capabilities.

## 3. One-page strategy statement

From *Can You Say What Your Strategy Is?* (HBR):

| Block | Prompts |
|-------|---------|
| Objective | What measurable end state by when? |
| Scope | Which customers, products, geographies, channels — and explicit **won't do** |
| Advantage | External: value proposition. Internal: activity system only we can run |

---

## 4. Porter Five Forces — analysis checklist

For each force, rate **low / medium / high** impact on industry profitability and explain **why**.

| Force | Sample evidence |
|-------|-----------------|
| Rivalry | # players, growth rate, differentiation, exit barriers |
| Substitutes | Performance/price of alternatives |
| Buyers | Concentration, switching costs, price sensitivity |
| Suppliers | Concentration, uniqueness, forward integration threat |
| Entrants | Scale, capital, regulation, brand, access |

**Extension:** complements (e.g. platforms), regulation as structural force.

---

## 5. Value chain & profit pool

- Map stages from inputs → customer.  
- Note **where margin accumulates** (profit pool).  
- Identify **bottleneck power** and potential vertical conflict (e.g. studios vs distributors).  
- For digital/platform businesses, consider **value net** (multi-sided).

---

## 6. Key Success Factors (KSF)

Industry-specific capabilities/assets required to **win**. Distinct from generic best practices.

Typical analysis:
- Historic KSF (what mattered last 5–10 years)  
- Emerging KSF (what will matter given trends)  
- Your **gaps** vs KSF for entry or share gain

## 7. Competitive advantage dynamics

```
Snapshot (assets)          Over time (capabilities)
─────────────────          ───────────────────────
Brand, scale, IP     ←──   Culture, learning, partner mgmt
Distribution               Innovation pipeline
```

Ask: **Will this advantage still matter in 3 years? Is it widening or narrowing?**

## 8. Strategic fit & product/market matrix

**Fit test:** Given our stated scope, should we do X?

| Zone | Rule |
|------|------|
| Core | Design business for this — invest |
| Peripheral | Only if it strengthens core |
| Out of scope | Say no (even if profitable distraction) |

**Product/market matrix dimensions:** products × segments × geographies × channels → growth synergies.

## 9. BCG Matrix

| | High growth | Low growth |
|---|-------------|------------|
| **High relative share** | Star | Cash cow |
| **Low relative share** | Question mark | Dog |

**Investment priorities:** Stars > selected ? marks > defend cows > starve dogs.

**Pitfalls:** wrong unit of analysis; correlated businesses treated as independent; emotional reinvestment in dogs.

## 10. GE Matrix

Dimensions:
- **Market attractiveness:** size, growth, margins, accessibility  
- **Competitive position:** KSF fit, differentiation, strength vs rivals  

Use for **prioritizing adjacencies** when BCG’s growth/share axes are too coarse.

## 11. Market entry toolkit

1. Define adjacency type (product / segment / geo / channel / value chain).  
2. Five Forces + profit pool for target market.  
3. KSF gap analysis.  
4. Which **assets/processes/values** transfer?  
5. Entry mode: organic / partner / JV / M&A.  
6. **Bowling alley:** narrow beachhead → adjacent pins.  
7. Disruptive vs sustaining → predict incumbent response.  

---

## 12. Disruptive vs sustaining

| Dimension | Sustaining | Disruptive |
|-----------|------------|------------|
| Customer | Best / most profitable | Overlooked, low-end, new context |
| Performance | Better on established metrics | “Good enough” + different metrics |
| Incumbent incentive | Defend aggressively | Ignore or flee upward |
| Examples | EV capex by OEMs | Digital photography, Wikipedia, mini-mills |

GenAI can be **both** — classify per use case.

## 13. Value disciplines

| Discipline | Must excel at | Must be good enough at |
|------------|---------------|------------------------|
| Operational excellence | Cost, reliability, convenience | Product, intimacy |
| Customer intimacy | Solutions, relationships | Cost, product |
| Product leadership | Innovation, speed to market | Cost, intimacy |

**Rule:** Trying to lead on all three = no strategy (no trade-off).

---

## 14. Scenario planning

Steps:
1. Identify critical uncertainties (not everything).  
2. Build 2–4 **consistent** stories of the future.  
3. Derive **implications** and **early warning indicators**.  
4. Stress-test strategy under each — adjust options.  

Not for forecasting accuracy — for **better decisions**.

---

## 15. Implementation bridge

| Failure mode | Fix |
|--------------|-----|
| Strategy not in budget | Explicit line items + owner |
| No metrics | Link to strategic thinking loop — **leading** indicators first |
| Org silos misaligned | One-page strategy everyone can repeat |
| Fluff objectives | Replace with objective/scope/advantage |
| Scaling before proof | Lean experiments before full rollout |
| Values/practices confusion | Separate timeless values from adaptable operating practices |

**Performance diagnosis (off-track):**

| Diagnosis | Question |
|-----------|----------|
| Execution failure | Sound strategy, weak capabilities/alignment/catalytic mechanisms? |
| Assumption failure | Experiments/pilots invalidated key assumptions? |
| Strategic flaw | Value prop / advantage no longer relevant? |

**Catalytic mechanisms:** Simple rules that force behavior (Collins) — e.g. “every initiative must name Attack/Defend/Exit.”

**Imitation blockers (fit depth):** 1st order consistency → 2nd order reinforcing loops → 3rd order optimized interlock — harder to copy than isolated activities.

```
              ┌──────────────────┬──────────────────┐
Global scale  │  Compelled by    │  Naturally       │
              │  costs           │  global          │

Local scale   │  Naturally local │  Customer-driven │
              └──────────────────┴──────────────────┘
```

**Profitable expansion checklist:** strong domestic core · repeatable formula · portable differentiation · favorable host Five Forces.

## 17. Platforms & multisided markets

```
Side A ←── platform ──→ Side B
         (interaction)
Value to A ↑ as B grows; value to B ↑ as A grows
```

**Design choices:** which side to subsidize · pricing decoupled from direct cost · start narrow then scale liquidity · avoid over-building before content/network ready.

**Patterns:** razor/blade · freemium · two-sided liquidity · winner-take-most when loops compound.

---

## 18. Digital trends & reinforcing loops

| Loop type | Mechanism | Examples |
|-----------|-----------|----------|
| Data | Usage → data → personalization → value | Google, Netflix, Alexa |
| Network | More users → more connections → value | WhatsApp, WeChat |
| Liquidity | Supply ↔ demand on platform | eBay, app stores |

**Trend bets:** No regrets (base) · Big bets (conviction) · Long shots (options/insurance).

**Digital profit shift:** Friction removal often hurts **mid-tier** undifferentiated players; helps **top brands** and **global niches**.

---

## 19. Core competencies & option evaluation

**Core competence test (Prahalad & Hamel):** Hard to imitate · contributes to customer value · provides access to **multiple** markets.

**Option scorecard:** Size of prize · ability to win · partnerships · implementation barriers · experiment design for uncommitted bets.

**Poker vs roulette:** Small scatter bets vs concentrated predatory leap when window opens.

---

## 20. Entrepreneurial strategy balance

```
Stable industry          Fast-changing industry
────────────────         ────────────────────
Analysis & planning  ←→  Trials & learning
NPV gates            ←→  Leading metrics
Few big projects     ←→  Many cheap experiments
```

**Lean startup:** Value hypothesis + growth hypothesis proven before scale. Corporate pitfall: impatient for growth, patient for profit (Christensen).
