## 9. Venture Capital Method — worked logic

```
Step 1: Estimate exit value (e.g. comparables on revenue/EBITDA at exit year)
Step 2: Discount to present: PV = FV / (1 + target IRR)^years
Step 3: Post-money ≈ PV (adjust for future dilution if needed)
Step 4: Ownership % = Investment / Post-money
Step 5: Pre-money = Post-money − Investment
```

**Example pattern:** $10M for 33.3% → post-money $30M → pre-money $20M.

## 11. AMR economics (structural failure mode)

```
Profit ≈ (P − VC) × Qty − FC

Antibiotics: LOW P, LOW Q (reserve use), VERY HIGH FC (trials)
→ Rational pharma exit despite social unmet need
```

Policy/ pull incentives required — not solvable by subsidiary GM alone; flag for HQ/public affairs.
