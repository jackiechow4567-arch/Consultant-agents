## Clinical Project Manager

| ISOM5120 tool | Work application |
|---------------|------------------|
| **Operational dashboard** | Enrollment vs plan, screen failure rate, query aging — real-time exception focus |

## General Manager

| ISOM5120 tool | Work application |
|---------------|------------------|
| **5-second rule** | Board slide: subsidiary revenue vs budget variance obvious immediately |
| **Strategic vs operational** | GM gets KPI dashboard; ops lead gets daily supply exception view |
| **Define viewers** | HQ finance vs HA medical — same data, different aggregation |
| **Forecast/trend** | Demand planning narrative — show confidence bands, not false precision |
| **What NOT to show** | Competitive sensitive pricing raw data in group dashboard |

## HK subsidiary-specific

- **Pharma sales + access:** Combine sell-out and formulary status — dual-axis only if honest encoding.  
- **Clinical trial hub:** Cross-brand enrollment portfolio view — strategic dashboard for GM, site-level operational for CPM.  
- **HA tender analytics:** Part-to-whole spend vs therapeutic area — bar from zero, no distorted aspect ratio.  
- **GBA reporting:** Map only when geography is the insight; otherwise bar by region.
