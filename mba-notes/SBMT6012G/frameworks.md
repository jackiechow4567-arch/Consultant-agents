## 3. AI race — analysis template

| Step | Question |
|------|----------|
| 1 | Is this **capability**, **resource**, or **ecosystem** competition? |
| 2 | **Sprint (AGI)** or **marathon (dependency)** framing by each actor? |
| 3 | Which **chokepoints** bind the decision (GPU, data, energy, talent, regulation)? |
| 4 | What **state tools** are already in play (subsidy, control, alliance, espionage)? |
| 5 | **Corporate options:** comply, substitute, dual-source, localize, delay, lobby |
| 6 | **Residual risk** after option — reversibility? |

## 4. Semiconductor supply chain — chokepoint map

```
LAYER              WHO CONCENTRATES?           FAILURE MODE
────────────────   ───────────────────────     ──────────────────────────
EDA software       US (3 firms)                Design freeze / compliance block
Fabless design     US (+ global)               IP, entity restrictions
Fab equipment      ASML (EUV), US/JP           No alternative node path
Foundry            TSMC, Samsung, Intel        Capacity, geopolitical shock
Assembly           CN/TW                       Disruption, not usually leading-edge
End use            Hyperscalers + states       Demand pull, procurement rules
```

**When to use:** Vendor risk, capex, cloud/AI infra, medical device compute, any “where is this chip from?” question.

**When NOT to use:** Routine SaaS with no custom silicon; pure software with no export-controlled components (still check data residency).

## 5. US–China policy contrast (course framing)

| China ascent tools | US response tools |
|--------------------|-------------------|
| Subsidies, tax credits | CHIPS Act funding |
| R&D, talent recruitment | Export controls, entity lists |

## 6. Nvidia case — decision framework (generic)

```
STAKEHOLDER PRESSURE
├── US Commerce (control tightening, anti-loophole)
├── Chinese customers (switch to local GPUs)
├── Investors (growth in AI datacenter)
└── Engineers (product segmentation complexity)
        │
        ▼
OPTIONS MATRIX
| Option | Revenue | Compliance | Substitution risk | Narrative |
        │
        ▼
RECOMMENDATION + TRIGGERS (rule change, competitor parity, revenue floor)
```

Use for **any** dual-market tech vendor — not Nvidia-specific facts in agent output.

| Signal | Action |
